# SDanShare
A device for sharing the SD card between a Dandanator Multiply and Windows PC.

With this device the SD card for the Dandanator Multiply can remain in the Multiply and connected to the ZX Spectrum while powered on. At the same time it can be connected to a powered on PC. A press of the button will then let you switch between the two modes and a LED which tell you which mode you are in. 

This is useful if you want to curate game collections and delete or add games quickly without removing the SD card from the Multiply.
