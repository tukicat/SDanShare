# SDanShare
A device for sharing the SD card between a Dandanator Multiply and Windows PC.

With this device the SD card for the Dandanator Multiply can remain connected to the ZX Spectrum and powered on. At the same time it can be connected to a powered on PC. A press of the button will then let you switch between the two modes, and a LED which tell you which mode you are in. 

This is useful if you want to curate game collections and delete or add games quickly without removing the SD card from the Multiply.

I have tested this device on a ZX Spectrum +2 (Grey) with a Windows 11 PC. There is no reason why it should work on other spectrum models, but i'll leave that for others to test.
